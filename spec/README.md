# Personal Assistant — Project Spec Kit
version: 1.0.0
last updated: 2024-11-12

## What This Is
A personal daily assistant that lives in Telegram.
Helps capture everything on your mind, clarify what each item really is,
and prioritize so you always know what to do next.

## Core Problem Being Solved
- Don't know what to do today
- Everything lives in your head
- Don't know if something is a task, project, or goal
- Hard deadlines and recurring tasks get forgotten
